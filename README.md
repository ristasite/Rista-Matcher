## Click behavior
Clicking a profile image, profile card, `View Match`, or `Explore More Matches` opens the configured Adsterra SmartLink in a new tab.

## Setup
1. Open `config.js`.
2. Replace `SMARTLINK_URL` with your Adsterra SmartLink.
3. Add your Adsterra ad snippets to the matching `ADS` fields.
4. Upload the entire project to GitHub.
5. Connect the repository to Cloudflare Pages.
6. Test every profile image/card and the SmartLink after deployment.

## Image rights
Use only images that you own or have permission/licensing to publish. One supplied image visibly contains a social-media username/watermark; remove it or use a properly licensed clean version before publishing if it is not yours.
